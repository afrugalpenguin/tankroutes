# Tank Routes

A WoW Forever addon that shows the current dungeon's map in a small window with a tank route drawn on it: numbered stops joined by a path, with an optional note on each stop. Built to help tanks learn dungeons.

Status: early development, not yet released.

## Planned for v1

- Small, movable, resizable map window that opens when you enter a dungeon with a route
- Route drawn as numbered stops and bend points, with mouse-over notes
- In-window editor: click to add stops, shift-click for bends, drag to move, undo
- Bundled routes for supported dungeons

## Credits

Dungeon map layouts for classic dungeons come from Forever Simple World Map by Tarolg (MIT). The room images are the game client's own minimap textures.
